# agro30-dados

Dados de mercado lidos pelo site Agro30 (agro30.netlify.app).

- `dados.json`: cotações, Status Agro (plantio/colheita), Conab, taxas, agenda e destaques.
- Atualizado nos dias úteis às 6h52 e 18h52 (horário de Brasília) por tarefa agendada.

Fontes: Cepea/ESALQ, Banco Central do Brasil, IBGE, Imea, Safras & Mercado, Conab e MAPA. Conteúdo: Agro Valentin.
